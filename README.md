# 한국 로또 6/45 AI 마스터 (Korean Lotto AI Master)

본 프로젝트는 동행복권 API를 활용하여 실제 한국 6/45 로또 당첨 이력을 수집하고, 고급 수학 및 통계 알고리즘(12종)과 파이썬 기반의 강력한 필터링 엔진을 결합하여 최적의 로또 번호를 추천해주는 AI 기반 웹 애플리케이션입니다.

## 주요 기능 (Features)

1. **실시간 당첨 데이터 동기화**
   - 동행복권 공식 API를 통해 262회차부터 최신 회차까지의 당첨 내역을 자동으로 수집합니다.
   - 브라우저의 `localStorage`를 활용한 스마트 캐싱 시스템으로 불필요한 API 호출을 방지하고 빠르게 로드합니다.

2. **양자 변동 추천 엔진 (Quantum Flux Engine)**
   단순한 무작위 추출이 아닌, 12가지의 수학적·통계적 기법을 통합하여 각 번호의 가중치를 정밀하게 계산합니다.
   - **수학적 모델링:** 가우스 정규분포, 피보나치/황금비(φ), 피타고라스 비율 구조
   - **통계적 패턴:** Pareto 80/20 법칙, Whitson 패턴 법칙, 양자 요동 노이즈(Box-Muller)
   - **평균 회귀 기술 지표:** Z-Score 통계 보정, MA 빈도추세, RSI 빈도모멘텀, 볼린저밴드 편차, Aroon 갭재귀
   - **시너지 분석:** 동반출현(Co-Occurrence) 점수 반영

3. **파이썬 기반 고급 필터링 (Advanced Python Filters)**
   파이썬 필터링 스크립트를 TypeScript로 포팅하여 실시간 브라우저 검증 파이프라인을 구축했습니다.
   - **AC Value (산술복잡도):** 번호 간 차이의 고유값을 계산해 지나치게 규칙적인 패턴 차단
   - **Sum46 (합46):** 두 수의 합이 46이 되는 쌍을 통계적 최대 허용치(0~2개)로 제한
   - **Ratio (분할 비율):** 큰 번호 3개와 작은 번호 3개의 합 비율 조절 (쏠림 방지)
   - **Range Pattern (번대 분산):** 특정 번대(단번대, 10번대 등)에 번호가 몰리지 않도록 제한
   - **Consecutive (연속 번호):** 3연속 번호 원천 차단 및 2연속 번호 최대 쌍 제한
   - **Total Sum (총합):** 6개 번호의 총합을 확률적으로 유의미한 구간(85 ~ 189)으로 제한

4. **정밀 분석 및 시각화 리포트**
   - **회차별 동적 리포트:** 최근 당첨 번호를 클릭하면 구간 분포, 홀짝/고저 비율, 번호 합계 편차, 이전 회차 비교 등 상세 리포트를 인라인으로 제공합니다.
   - **개별 번호 정밀 분석:** 특정 번호 클릭 시 출현 횟수, 연속 출현, 평균 간격, 기술 지표(MA, RSI, BB, Aroon, Z-Score) 점수 및 동반 출현 번호 Top 10을 시각적으로 분석해 줍니다.
   - **전체 통계 요약:** 역대 빈도 순위(Hot/Cold), 전체 1~45번 출현율 프로그레스 바 등을 한눈에 파악할 수 있습니다.

## 실행 방법 (Run Locally)

**사전 요구사항 (Prerequisites):** [Node.js](https://nodejs.org/) 설치

1. **패키지 설치**
   프로젝트 루트 디렉토리에서 터미널을 열고 아래 명령어를 실행하여 의존성을 설치합니다.
   ```bash
   npm install
   ```

2. **개발 서버 실행**
   아래 명령어를 통해 로컬 개발 서버를 실행합니다.
   ```bash
   npm run dev
   ```

3. **브라우저 접속**
   터미널에 출력된 로컬 주소 (예: `http://localhost:5173/`)로 접속하여 애플리케이션을 사용합니다.

## 기술 스택 (Tech Stack)

- **Frontend Framework:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS (v4)
- **Data Storage:** Browser `localStorage` (Client-side Caching)
- **API & Data:** 동행복권 오픈 API, GitHub 원격 조합 데이터(`lotto_combinations.txt`)
